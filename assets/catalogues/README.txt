BRAND CATALOGUE PDFs — NOT INCLUDED IN THIS PACKAGE
===================================================

The catalogue download buttons on the home page and the Services page link to
PDFs that live in this folder. They are left out of the handover ZIP because
together they are roughly 330 MB, which would make the archive impossible to
email and would bloat the git repository for every future clone.

Drop the PDFs into this folder, using EXACTLY these filenames, and every
download button works with no code change:

  bang-olufsen-catalogue.pdf
  d-link-catalogue.pdf
  delta-light-catalogue.pdf
  flos-catalogue.pdf
  grandstream-catalogue.pdf
  leccy-genesis-catalogue.pdf
  logitech-catalogue.pdf
  ltech-catalogue.pdf
  lumiverse-catalogue.pdf
  marshall-catalogue.pdf
  moorgen-catalogue.pdf
  prisha-illumination-catalogue.pdf
  promark-catalogue.pdf
  schneider-electric-catalogue.pdf
  sennheiser-catalogue.pdf
  sonos-catalogue.pdf
  tp-link-catalogue.pdf
  viewsonic-catalogue.pdf
  yale-catalogue.pdf
  yealink-catalogue.pdf

A better option than committing them to git: upload the PDFs to Netlify Large
Media, Google Drive or the brands' own sites and point the links there instead.
Every link is an ordinary <a href> in index.html and services.html, so changing
one is a one-line edit.
